# Skill: Code Review

Review for:
- Correctness
- Maintainability
- Architecture alignment
- Performance
- Error handling
- Edge cases
- Tests
- Documentation impact

**When you report more than one finding**, render them as a table per `workflow-rules.md` § Work listing format — one row per finding, filling the columns the project supports (e.g. `#`/location, area/category, severity, status) and omitting the rest. Never invent a value.
